    この行動での変化

    「1行動」の切り出し

    • ACTION_STARTED〜ACTION_COMPLETED を1行動とする
    • ターン開始・終了の処理（回復、継続効果の経過）はシステム行動として1つにまとめる
    • 処理ステップは SKILL_USE_*・TARGETS_SELECTED・DAMAGE_* などを意味単位に束ねたもの。右端の # が元イベントの sequence

    割り込みPSの表現

    • parentSequence が行動内の別イベントを指すPS発動は、紫の破線で1段字下げして表示
    • PS所持者から対象へ紫の矢印を引き、誰の効果かを盤面上で区別する

    操作

    • ← → 1単位、Shift＋矢印でN単位、Space 再生、Home End
    • 単位を「処理」にすると行動内を1ステップずつ進め、盤面もその時点の状態になる
    • 「追跡」で味方／敵の行動だけを飛ばし読みできる。タイムラインと右パネルの行もクリックで移動できる
