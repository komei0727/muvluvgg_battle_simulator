## 未確定の受け入れ条件

スキル単位の「要修正」という判定は全件記録済みだが、次の3論点は評価シートでも細部未確定として残っている。ここで推測して正しい仕様に補わない。**影響はSR-011・286・328の3件**で、他204件の着手を妨げない。

### U1：部分シールド無視の残量消費・複数枚・端数（SR-011・286／[FIX-15](#fix-15)）

確定：盾が50%／80%機能し、超過のみHPへ通る。未確定：元の盾残量を減らす量、多段の次ヒットへ残す量、複数枚の扱い、端数を切る順序。例えば無視50%・元盾2000・計算800でHP0という点は確定だが、残盾を1200にするか400にするか等は未指定。回答を[仕様確認事項](../../ddd/02_仕様確認事項.md)と[FIX-15](#fix-15)へ反映してから恒久期待値を決める。

## 完了の記録方法

- 1つの評価行に複数の修正Issueがある場合は、全担当の実装修正と再検証が揃うまで修正完了にしない。
- 「要修正」はレビュー時の判定として保持し、修正後は評価シートの対応状況・修正参照・再検証結果を更新する。起票しただけでは修正参照のPRや再検証結果を完了にしない。
- 設計書の具体的改訂は各実装修正と同じPRで実装・テスト・Catalogと同期する。
- 既存Issue #758はマーカーのスキル使用単位連動を扱う関連課題。FIX-06では付与元・期限を含む全付与分の独立管理を扱い、共通モデルの実装を二重化しない。
- この対応表と評価シート以外のレビュー資料・Issue案Markdownをmainに追加することを前提にしない。個別の変更範囲・受け入れ条件は起票した実Issue本文へ記載する。
